# SheGuardian 🛡️

> A women safety application designed to provide fast emergency assistance through voice-triggered SOS actions, live location sharing, and trusted-contact alerts.

## 📌 Overview

**SheGuardian** is a women safety application focused on providing quick access to emergency assistance when a user may not be able to manually operate their phone.

The application allows the user to configure a personal emergency **code word/phrase**. When the configured phrase is detected, the app can initiate predefined safety actions such as sharing the user's live location, contacting trusted people, and capturing emergency audio/video when the required permissions are granted.

## 🚨 Key Features

- **Voice-Triggered SOS** — Activate emergency actions using a user-defined code word or phrase.
- **SOS Button** — Provide a manual emergency trigger from the app dashboard.
- **Live Location Sharing** — Share the user's current/live location with selected trusted contacts.
- **Trusted Contacts** — Store up to 5 emergency contacts for quick alerts.
- **Emergency Calling** — Initiate calls to configured contacts during an emergency.
- **Audio/Video Capture** — Capture emergency evidence when the user has granted the required permissions.
- **Emergency Notifications** — Send alerts to configured contacts with relevant emergency information.
- **Multi-Language Support** — Designed to support users across different languages.
- **Safety Dashboard** — Central place for SOS controls, emergency settings, and trusted contacts.

## 👥 Trusted Contacts

Users can configure trusted emergency contacts who may receive alerts during an emergency.

**Maximum configured contacts: 5**

Recommended information for each contact:

- Name
- Phone number
- Relationship/label

## 🗣️ Voice Activation

The user can configure a short emergency phrase/code word.

When the configured phrase is recognized, the application can trigger the user's selected emergency workflow.

> Voice recognition accuracy can vary depending on the device, microphone quality, background noise, language, and operating-system restrictions.

## 🎯 Project Objective

The primary objective of SheGuardian is to reduce the time between an emergency situation and the activation of help.

Instead of requiring multiple manual steps, the application aims to provide a simple emergency mechanism that can be activated through a configured voice phrase or SOS control.

## ⚠️ Important Disclaimer

SheGuardian is a safety-support application and should **not be considered a replacement for emergency services, law enforcement, or professional assistance**.

Feature availability depends on the device, operating system, network connectivity, permissions, and implementation. Emergency actions such as calls, location sharing, and media capture may fail or behave differently under certain device or operating-system restrictions.
